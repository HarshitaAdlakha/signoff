Sign off on today's data.

This page pulls the live Citi Bike feed every minute and runs Signoff's own data contract, remediation options and trust gate on it: the same modules the agents run. Whatever is wrong with the feed right now becomes an incident. You decide the fix as Paras, or try as Harshita and get refused. Then ask the analyst where to send a truck.

In the full system these agents are separate Switch agents talking through two Switch rooms in Mattermost, and Switch's addressing policy enforces the sign-off. Here the two rooms are drawn in the page so anyone can try it without installing anything. Run the real Switch version with five commands, or watch the replay of a recorded Switch session.
