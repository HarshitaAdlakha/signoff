Why Switch is central

Take Switch away and there's
no hand-off, no sign-off, no gate.

rooms → mattermost
create_room(people, agents, instructions, roles, links)
roles, exclusive
send_targeted_message( target_roles=["remediator"])
addressing = the sign-off gate
fixer.addressing = "owner_and_owner_agents"
room documents = shared state
data-status · incident-log postmortem-INC-00x
threads · linked rooms
one incident = one thread desk ⇄ incidents, labelled
agent protocol, no SDK
WebSocket events + ping/pong HTTP ops · resume from cursor

Our agents never call each other. Every hand-off, approval and refusal goes through the room, where people can see it.

Standing rules
Every option is previewed, applied in one transaction with the approver's name, and verified on the next run. Nothing deleted.
Bounded fallbacks
Feed frozen → "answer from the last good data, stating its age, for up to 30 minutes". After that the analyst refuses again.
A silent watcher is a failed watcher
No run in 3 minutes → untrusted, whatever the document says.
